## Повторение

Использовать `schedule_ingestion.tests.replay_postgres` из изолированной среды,
описанной в `tools/tableparser-validation/README.md`. Перед вызовом выполнить
миграции с `--settings=schedule_ingestion.tests.postgres_settings`, затем
`import_tableparser_knowledge SOURCE_SQLITE --apply` с теми же настройками.

```text
python -m schedule_ingestion.tests.replay_postgres --source SOURCE_SQLITE --state RESOURCE_ROOT --baseline BASELINE_ROOT --output NEW_OUTPUT_DIRECTORY
```

`TABLEPARSER_TEST_PG_PORT` указывает порт временной БД на localhost.
Исходный снимок: TableParser `data/state_bundles/replay-2026-10-06/runtime/data/knowledge.sqlite3`.
Ресурсы: `data/package-replays/verified-2026-10-07/state`.
Эталон: `data/state_replays/knowledge-reader-2026-10-07`.
Каталог результата должен быть новым; исходники и ресурсы — только для чтения.
Проверка прекращается при первом расхождении и не создаёт успешный `completed.json`.
